# NEXT STEP V4 — operations, security and decision depth

## Цель итерации

Перевести текущий list-first MVP из набора каталогов в управляемую операционную симуляцию. Сотрудники больше не дают скрытый глобальный бонус: игрок собирает отдельные проектные команды. Безопасность становится отдельным бюджетируемым контуром, а рынок и финансы получают объясняющие экраны.

## Реализуемая цепочка

1. Создать продукт.
2. Нанять нескольких специалистов.
3. Открыть «Операции» и назначить людей на конкретный продукт.
4. Увидеть изменение development capacity и ETA.
5. Обучить сотрудника, повысить зарплату или уволить с компенсацией.
6. Открыть «Центр безопасности», провести аудит и внедрить контроли.
7. Увидеть новый риск атаки, setup/OPEX и коэффициент incident probability.
8. Сравнить продукт с конкурентами по метрикам и понять веса сегментов.
9. Проверить P&L, burn, runway, cap table и внешний портфель.
10. Сохранить игру, перезапустить и убедиться, что назначения, контроли и аудиты восстановились.

## Новые правила

- один сотрудник одновременно назначен максимум на один продукт;
- неназначенный сотрудник находится в резерве и не ускоряет все продукты одновременно;
- продукт без команды продолжает двигаться только с базовой мощностью основателя;
- обучение меняет конкретные числовые показатели сотрудника и требует денег;
- повышение зарплаты увеличивает payroll, morale и loyalty;
- увольнение требует компенсации 50% месячной зарплаты;
- security control имеет setup cost, monthly OPEX, security delta, reliability delta и incident multiplier;
- риск атаки учитывает категорию, масштаб, security score, server load и набор контролей;
- аудит фиксирует risk percent и число findings в snapshot;
- snapshot v4 мигрирует сохранения v3 без удаления продуктов, сотрудников и сделок.

## Не входит в эту итерацию

- полноценный task board с отдельными engineering tickets;
- переговоры по зарплате и контрофферы сотрудников;
- исторические cohort-графики по месяцам;
- полноценная бухгалтерская книга каждой транзакции;
- мультиплеер, онлайн-сервисы и backend.
