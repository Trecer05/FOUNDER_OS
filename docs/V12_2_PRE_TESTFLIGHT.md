# FOUNDER.OS v12.2 pre-TestFlight

Цель этапа — закрыть физический UAT перед первой внешней тестовой сборкой, не меняя базовую архитектуру и snapshot schema v12.

## Исправлено

- «Новая компания» выполняет атомарный полный сброс симуляции: день, продукты, сотрудники, назначения, контракты, финансы и старый профиль не переживают новый цикл. Display preferences остаются глобальными настройками вне snapshot.
- CEO остаётся отдельной сущностью, не превращается в Employee и не занимает payroll/headcount. В UI команды он показан как автоматический участник, а отображаемая скорость разработки использует сумму employee capacity + founder capacity.
- Один сотрудник может вести максимум четыре активные работы (продукты и контракты вместе). Эффективность на каждой работе: 100% / 70% / 55% / 40% для 1 / 2 / 3 / 4 работ.
- При принятии клиентского контракта движок детерминированно подбирает подходящих наименее загруженных сотрудников по требуемым ролям. Карточки до и после принятия показывают достаточность команды.
- У выпущенного продукта активная линейка четырёх стадий больше не отображается на продуктовых карточках и рабочих экранах.
- Финальная проверка проекта 7/7 получает единообразные полноширинные summary tiles с ровными отступами и визуальной иерархией.
- Дизайн-этап теперь развивается от намеренно рыхлого wireframe к фиксированной понятной сетке; расположение блоков интерполируется к финальной структуре по прогрессу этапа.
- Ежедневные inline mini-games заменены одним необязательным техническим вызовом на проект. Он появляется модально поверх интерфейса в разработке/отладке. Правильный ответ даёт +30% диапазона текущего этапа; пропуск и ошибка не штрафуют.

## Проверка

`tools/verify_v12_2_pre_testflight.sh` выполняет:

1. static audit v12.2;
2. offline pub resolution;
3. dart format;
4. flutter analyze;
5. focused v12.2 domain tests;
6. focused v12.2 widget tests;
7. обновлённую regression-проверку challenge;
8. полный существующий v12.1 verifier, включая весь Flutter suite и iOS/Android debug builds;
9. git diff --check.

После автоматического verifier обязателен physical iPhone UAT. До него commit/push не выполнять.
